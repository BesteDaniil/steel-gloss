# STEEL & GLOSS — сайт-система детейлинг-центра

Демо-проект для портфолио: не лендинг, а интерактивная система расчёта. Клиент выбирает класс машины, пакеты услуг и зоны бронеплёнки прямо на схеме кузова. Смета пересчитывается сразу, заявка уходит одной кнопкой.

> Компания и цены вымышлены. Данные формы никуда не отправляются.

**Живой сайт:** https://bestedaniil.github.io/steel-gloss/

## Что внутри

Четыре страницы, связанные общим состоянием. Выбор не теряется при переходах, перезагрузке и кнопке «Назад».

| Страница | Что на ней |
|---|---|
| `index.html` | Презентация центра. SVG-машина «прорисовывается» линиями, по ней бежит блик. Кнопка «Перейти к расчету сметы». |
| `calculator.html` | **Шаг 1.** Класс машины (radio): седан ×1.0, кроссовер ×1.2, внедорожник ×1.4. Пакеты (checkbox): цена уже с коэффициентом класса. При наведении карточка увеличивается до 1.02 и у неё проявляется неоновая граница. |
| `map.html` | **Шаг 2.** SVG-карта кузова: схема проявляется из размытия, зоны появляются по очереди. Восемь зон работают мышью и с клавиатуры (Tab → Enter/Space). Полная оклейка включает все зоны и блокирует точечный выбор. Если зоны дороже полной оклейки, появляется подсказка с экономией. Клики по стёклам, колёсам и зеркалам ничего не выбирают. |
| `checkout.html` | **Шаг 3.** Детальная смета в порядке прайса, итог плавно «перебегает» к новому числу. Форма с маской телефона и своей валидацией, модальное окно «Заявка принята» на нативном `<dialog>`, кнопка «Начать новый расчёт». |

Во всех страницах есть шапка с шагами 01–02–03 и итогом сметы. На шагах 1 и 2 внизу липкая плашка с итогом и кнопкой «Далее».

**Анимации.**
- Элементы появляются из размытия: CSS-класс `.enter`, задержка задаётся через `--i`. Если JS не загрузится, контент всё равно станет видимым.
- Переходы между страницами — View Transitions API (`@view-transition`). Шапка остаётся на месте, страница перетекает с лёгким размытием. Браузеры без поддержки переключают страницы как обычно.
- При `prefers-reduced-motion` движение отключается.

Стек: HTML, CSS и чистый JS на ES-модулях. Без фреймворков, библиотек, сборщиков и фото: вся графика — SVG/CSS.

## Как открыть локально

**Двойной клик по `index.html` не сработает.** Браузер не загружает ES-модули (`<script type="module">`) со страницы, открытой как `file://`: увидите пустые блоки и ошибку CORS в консоли. Нужен любой локальный сервер:

```bash
# из папки проекта
python -m http.server 8137
# открыть http://127.0.0.1:8137/
```

Другой вариант — расширение **Live Server** в VS Code: правый клик по `index.html` → «Open with Live Server».

## Тесты

```bash
npm test                  # юнит-тесты: node --test для pricing.js, validation.js, persistence.js
node tests/e2e.mjs        # E2E в настоящем Chrome (сначала запустить сервер на 8137)
```

- Юнит-тесты покрывают:
  - сохранение: битый JSON, старая версия формата, неизвестные и повторяющиеся id, не-массивы;
  - коэффициенты классов, округление до 100 ₽, порядок позиций, полную оклейку без дублей зон, подсказку экономии, маску телефона (ввод с 8 / 7 / +7, вставка, Backspace через «) » и «-»), все правила валидации.
- E2E (`tests/e2e.mjs`) управляет Chrome через DevTools Protocol, без Playwright и зависимостей. Клики идут настоящими событиями мыши, ввод — клавиатуры. Сценарии:
  - путь клиента по 4 страницам: главная → конфигуратор → карта → смета;
  - выбор сохраняется после перезагрузки и кнопки «Назад»;
  - две вкладки синхронизируются;
  - битые данные в хранилище не ломают сайт;
  - внедорожник + керамика = 49 000 ₽;
  - увеличение карточки при наведении;
  - клики по декору карты ничего не выбирают;
  - полная оклейка без дублей зон;
  - маска телефона и Backspace;
  - модалка и «Начать новый расчёт»;
  - вёрстка на 375 px. Скриншоты: `SHOTS_DIR=папка node tests/e2e.mjs`. Путь к браузеру задаётся через `CHROME_PATH`.

## Архитектура

```
index.html  calculator.html  map.html  checkout.html
css/base.css           — дизайн-токены в :root, шапка с шагами, кнопки, плашка шага, анимации и переходы
css/home.css  calculator.css  map.css  checkout.css — стили своей страницы
js/pricing.js          — все цены и коэффициенты + чистые функции расчёта (без DOM)
js/validation.js       — маска телефона и правила формы (без DOM)
js/persistence.js      — сохранение в localStorage: проверка данных, защита от недоступного хранилища
js/store.js            — единое состояние { carClassId, selectedPackages[], selectedZones[] } + подписка;
                         сохраняет каждое изменение, синхронизирует вкладки (storage) и «Назад» (pageshow)
js/nav.js              — шаги в шапке, итог в шапке и в плашке шага
js/configurator.js     — шаг 1: класс машины и пакеты
js/bodymap.js          — шаг 2: SVG-карта кузова
js/estimate.js         — шаг 3: смета
js/phone-mask.js       — маска телефона на поле (DOM-обвязка над validation.js)
js/form.js             — шаг 3: форма, валидация, модалка
js/pages/*.js          — точки входа страниц: подключают нужные модули
tests/                 — юнит-тесты (node --test) и E2E
```

**Почему хранилище не принимается на веру.** `localStorage` бывает недоступен (приватный режим, запрет cookies), переполнен или хранит данные старой версии сайта. `persistence.js` оборачивает каждое обращение и пропускает сохранённое через `sanitizeState`: битое отбрасывается, неизвестные услуги удаляются. Если сохранять нельзя, сайт работает, а на странице появляется предупреждение.

Модули не вызывают друг друга. Они меняют состояние через `store.js` и перерисовываются по подписке.

**Новая услуга — одна строка** в `PACKAGES` в `js/pricing.js`, карточка появится сама. **Новая зона** — строка в `ZONES` плюс контур в `ZONE_SHAPES` в `js/bodymap.js`: геометрия относится к виду, а не к прайсу.

## Публикация на GitHub Pages

1. Создать репозиторий `steel-gloss` и отправить в него код (ветка `main`).
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт будет по адресу `https://<логин>.github.io/steel-gloss/`.

То же из терминала через GitHub CLI:

```bash
gh repo create <логин>/steel-gloss --public --source=. --push
gh api -X POST repos/<логин>/steel-gloss/pages -f "source[branch]=main" -f "source[path]=/"
```

После правок поднимайте версию во **всех четырёх** страницах, иначе у посетителей останется старая версия из кэша: у CSS — `?v=N` в `<link>`, у JS — `?v=N` нужного модуля в `<script type="importmap">` (там перечислены все модули) и у точки входа `js/pages/*.js`.
