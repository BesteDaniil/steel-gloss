# STEEL & GLOSS — сайт-система детейлинг-центра

Демо-проект для портфолио: не лендинг, а интерактивная система расчёта. Клиент выбирает класс машины, пакеты услуг и зоны бронеплёнки прямо на схеме кузова. Смета пересчитывается сразу, заявка уходит одной кнопкой.

> Компания и цены вымышлены. Данные формы никуда не отправляются.

**Живой сайт:** https://bestedaniil.github.io/steel-gloss/

## Что внутри

- **01 Конфигуратор.** Класс машины (radio): седан ×1.0, кроссовер ×1.2, внедорожник ×1.4. Пакеты (checkbox): цена в карточке уже с коэффициентом класса.
- **02 Карта кузова.** SVG, вид сверху. Восемь зон кликаются мышью и с клавиатуры (Tab → Enter/Space). Полная оклейка включает все зоны и блокирует точечный выбор. Если выбранные зоны дороже полной оклейки, появляется подсказка с экономией.
- **03 Смета и заявка.** Позиции идут в порядке прайса, итог плавно «перебегает» к новому числу. На телефоне внизу липкая плашка с итогом. Форма с маской телефона и своей валидацией, успех показывается в нативном `<dialog>`.

Стек: HTML, CSS и чистый JS на ES-модулях. Без фреймворков, библиотек, сборщиков и фото: вся графика — SVG/CSS.

## Как открыть локально

**Двойной клик по `index.html` не сработает.** Браузер не загружает ES-модули (`<script type="module">`) со страницы, открытой как `file://`: увидите пустые блоки и ошибку CORS в консоли. Нужен любой локальный сервер:

```bash
# из папки проекта
python -m http.server 8137
# открыть http://127.0.0.1:8137/
```

Другой вариант — расширение **Live Server** в VS Code: правый клик по `index.html` → «Open with Live Server».

## Тесты

```bash
npm test                  # юнит-тесты: node --test для pricing.js и validation.js
node tests/e2e.mjs        # E2E в настоящем Chrome (сначала запустить сервер на 8137)
```

- Юнит-тесты покрывают: коэффициенты классов, округление до 100 ₽, порядок позиций, полную оклейку без дублей зон, подсказку экономии, маску телефона (ввод с 8 / 7 / +7, вставка, Backspace через «) » и «-»), все правила валидации.
- E2E (`tests/e2e.mjs`) управляет Chrome через DevTools Protocol, без Playwright и зависимостей. Клики идут настоящими событиями мыши, ввод — клавиатуры. Сценарии: внедорожник + керамика = 49 000 ₽, капот в смете, полная оклейка, подсказка экономии, пустая и валидная форма, модалка, Backspace в телефоне, липкая плашка на 375 px. Скриншоты: `SHOTS_DIR=папка node tests/e2e.mjs`. Путь к браузеру задаётся через `CHROME_PATH`.

## Архитектура

```
index.html
css/style.css        — дизайн-токены в :root (цвета, отступы, радиусы, шрифты)
js/pricing.js        — все цены и коэффициенты + чистые функции расчёта (без DOM)
js/validation.js     — маска телефона и правила формы (без DOM)
js/store.js          — единое состояние { carClassId, selectedPackages[], selectedZones[] } + подписка
js/configurator.js   — модуль 1: класс машины и пакеты
js/bodymap.js        — модуль 2: SVG-карта кузова
js/estimate.js       — модуль 3: смета и липкая плашка итога
js/phone-mask.js     — маска телефона на поле (DOM-обвязка над validation.js)
js/form.js           — модуль 3: форма, валидация, модалка
js/main.js           — точка входа
tests/               — юнит-тесты (node --test) и E2E
```

Модули не вызывают друг друга. Они меняют состояние через `store.js` и перерисовываются по подписке.

**Новая услуга — одна строка** в `PACKAGES` в `js/pricing.js`, карточка появится сама. **Новая зона** — строка в `ZONES` плюс контур в `ZONE_SHAPES` в `js/bodymap.js`: геометрия относится к виду, а не к прайсу.

## Публикация на GitHub Pages

1. Создать репозиторий `steel-gloss` и отправить в него код (ветка `main`).
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт будет по адресу `https://<логин>.github.io/steel-gloss/`.

То же из терминала через GitHub CLI:

```bash
gh repo create <логин>/steel-gloss --public --source=. --push
gh api -X POST repos/<логин>/steel-gloss/pages -f "source[branch]=main" -f "source[path]=/"
```

После правок поднимайте версию в `index.html`, иначе у посетителей останется старая версия из кэша: у CSS — `style.css?v=N`, у JS — `?v=N` нужного файла в `<script type="importmap">` (там перечислены все модули) и у `main.js`.
